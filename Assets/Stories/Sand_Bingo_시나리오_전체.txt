마지막 인사는 늘 지난 뒤에야 알게 된다

몇십 년째 거의 말라버린 이 땅에서, 곁에 있던 얼굴들은 손가락 사이 모래처럼 빠져나갔다

파이퍼는 그중에서도 가장 밝고 낭만적인 아이였다

그 아이는 말이 참 많았기에, 그녀가 없는 우물가는 이토록 조용할 수가 없었다

그녀는 이미 떠났고, 결국 마음속에 목소리만 남았다

남은 사람은 그 목소리를 오래오래 품고 다니다가, 어느 날엔 그마저—

파이퍼 : ……뭐라는 거야?

파이퍼 : 저 여기 있거든요? ...더위 먹었나?

파이퍼가 빈 물통을 한 손에 든 채, 어이없다는 얼굴로 서 있었다

테사 : 어, 왔구나.

테사 : 생각보다 빨리 왔네. 좀 더 천천히 와도 됐는데.

파이퍼 : 좀 더 천천히 와요? 제 장례식이라도 마저 치르시게?

테사 : ...저쪽 우물은 어땠어? 물이 조금이라도 나오는 것 같아?

파이퍼 : 참 나... 저쪽도 가망이 없어요. 테사 쪽은요?

테사 : 지금은 안 나오는데, 여기 보면 잘 건드리면 터져 나올 것 같지 않아?

파이퍼 : 어, 그러네요? 근데 왜 작업 안 하고 있었어요?

테사 : 요즘엔 너가 더 손재주가 좋잖아. 우리 에이스를 기다리고 있었지.

파이퍼 : 그냥 귀찮았던 거면서...

-----

파이퍼 : 알다시피 우물을 뚫기 위해선 '오아시스 모래'라는 특수하고 한정된 자원을 써야 돼요.

테사 : 근데, 왜 우물을 뚫는 데 또 모래를 써야 되지? 아직도 이해가 안 되네.

파이퍼 : ...이 일을 3년이나 했다면서 갑자기 그런 소리를 하는 거예요?

파이퍼 : 메마른 땅에 자극을 줘서 깊숙한 곳에 있는 물길을 위로 트이게 하는...

파이퍼 : 뭐... 대충 그런 원리의 소재 아니었어요?

테사 : 너무 대충인데. 여전히 이해가 안 가.

파이퍼 : 아무튼 오아시스 모래는 여기 이 부분, 이 영역 안에만 떨어트릴 수 있어요.

파이퍼 : 한 번에 쓸 수 있는 양은 정해져 있으니, 조금씩 신중하게 사용해야 돼요!

테사 : 맞아. 양 조절을 잘하는 게 핵심이야. 그건 나보다 너가 훨씬 더 잘하는 것 같아.

파이퍼 : 일정량의 오아시스 모래를 사용하고 나면, 그에 대한 반응으로 진흙이 쌓여요.

테사 : 진흙은 땅이 물에 젖고 있다는 좋은 신호지만, 반대로 한 곳에 너무 쌓이면 도로 우물이 막혀버려.

파이퍼 : 맞아요! 그러니 진흙이 쌓여서 서로를 잇기 전에, 오아시스 모래로 서로를 이어야 해요.

파이퍼 : 가로, 세로, 대각선 방향으로 5칸 이상을 연속으로 이으면

파이퍼 : 진흙이 쌓이기 전에 땅에 충분한 자극을 줄 수 있을 거예요!

-----

테사 : 물이 나오기 시작했어. 이 정도면 충분해.

테사 : 근데 가로, 세로, 음... '칸'? 그게 도대체 무슨 말이야?

파이퍼 : 글쎄요, 히히. 제 마음속 눈으로만 보이는 걸지도요.

테사 : 그래, 어련하겠어. 어쩐지 시작한 지 얼마 되지도 않았으면서 일을 그렇게 잘하더니.

테사 : 이래서 천재들에겐 벽이 느껴진다니까, 정말로...

파이퍼 : 얼른 출발해요. 저녁 전까지는 뚫릴 만한 다음 우물을 찾아봐야죠!

테사 : 그래 그래... 그 넘치는 에너지도 참 부러워.

테사 : 어?

파이퍼 : 왜 그래요?

테사 : 아무것도 아니야. 출발하자.

-----

파이퍼 : 덥네요.

테사 : 그러게... 해가 져 갈 때가 더 더운 것 같아.

파이퍼 : 물 뚫는 사람이 왜 더 목마르게 다녀야 하죠?

테사 : 몰라. 더우니까 복잡한 건 생각하기 싫어.

파이퍼 : 참 불공평하네요... 갑자기 의욕도 안 나고.

테사 : 썰렁한 얘기를 좀 해주면 시원해질까?

파이퍼 : 짜증나려고 하니까 그만둬요.

테사 : 좋아, 그럼 이건 어때?

테사 : 다음 우물만 뚫으면 선물을 하나 줄게.

파이퍼 : 됐거든요. 별로 관심 없어요.

파이퍼 : ...근데 뭔데요?

테사 : 음... 사실 나도 잘 모르겠어.

파이퍼 : 그런 게 어딨어요.

파이퍼 : 설마 그냥 하루 쉬게 해주겠다, 뭐 이런 거예요?

테사 : 그건 아니지.

파이퍼 : 그럼 뭐 우리들의 우정이나 노력의 뿌듯함 같은 건 아니겠죠?

테사 : 뭐 따지고 보면 비슷하긴 한데...

테사 : 잠... 잠깐만, 같이 가아아...!

-----

파이퍼 : 올라와요, 테사! 물이에요!

테사 : 휴... 이번 건 그래도 조금 힘들었어. 그치?

파이퍼 : 그러게요. 하마터면 관둘 뻔했어요.

테사 : 끝까지 해줘서 고마워. 물부터 한 모금 마시고 쉬고 있어.

파이퍼 : 테사도 수고했어요.

파이퍼 : 근데 뭐 잊은 거 없어요?

테사 : 아... 그래, 맞아.

테사 : 근데 그건 줄 수 있는 무언가는 아니야.

테사 : 들고 다닐 수 있는 게 아니라서.

파이퍼 : 점점 더 수상해지는데요.

테사 : 아는 곳이 있어. 좀 걸어야 되긴 한데...

파이퍼 : 휴... 그럼 조금만 더 쉬었다 출발할래요.

-----

테사 : 하아... 분명 여기 근처였는데...

파이퍼 : 언제까지 그냥 따라다녀야 해요? 벌써 해가 졌는데요.

파이퍼 : 뭐야, 이 풀떼기들은...

테사 : 마른 꽃대야. 예전에 물길 위에 피었던 것들이지.

테사 : 내가 기억하기로는 여기 근처에 아주 좋은 우물이 있어.

테사 : 터지기만 하면 오랫동안 물이 펑펑 쏟아져 나오거든.

테사 : 근데 그만큼 작업하기 어려운 곳이라서...

파이퍼 : 멈춘 뒤로 방치하고 있었군요.

테사 : 맞아... 근데 오늘이 바로 손을 댈 날인 것 같네.

파이퍼 : 미루던 귀찮은 일을 시작하게 하다니,

파이퍼 : 사실 이건 테사를 위한 선물이 아니었을까요?

테사 : 사소한 계기를 줘서 고맙구만 정말로...

파이퍼 : 어! 저거 아니에요?

테사 : 아, 잘 찾았어. 저거 맞아.

파이퍼 : 우와, 정말로 쉽지 않아 보이네요.

테사 : 그래도 성공하고 나면 이 근방은 한동안 좋은 수원이 될 거야.

테사 : 그럼 시작해볼까?

-----

파이퍼 : 푸하아! 나온다, 나온다아!!

파이퍼 : 우와, 조심해요! 이렇게 쏟아져 나온다니...!

테사 : 휴우... 수고했어. 에고, 다 젖어버렸네.

파이퍼 : 정말 힘들었어요. 아아... 그래도 시원하네요.

테사 : 그러게... 오늘 하루 종일 덥고 지쳤는데.

테사 : 이 순간만큼은 정말 뿌듯하네.

파이퍼 : 마음에 들어요. 기대했던 느낌은 아니었지만.

파이퍼 : 우와, 별 봐요. 오늘따라 엄청 많네요.

파이퍼 : 꼭 반짝이는 모래를 뿌려놓은 것 같지 않아요?

테사 : 저 정도면 하늘에도 우물이 하나 뚫리겠는걸.

파이퍼 : 그럼 한 번이라도 비라는 게 내려봤으면 좋겠네요.

오늘 밤엔 위아래가 잘 구분되지 않았다

발밑에서는 물이 솟고, 머리 위에서는 모래가 반짝였다

언젠가 아주 오랜 뒤에 이 밤을 떠올리게 될 것이다

그때는 오늘이 무엇의 시작이었는지도 알게 되겠지

그리고 그 이야기의 끝은 아마—

파이퍼 : 이제 그만! 끝!
