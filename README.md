## About

- Genre : Falling-sand puzzle
- Modes : Stages (Easy, Normal, Hard, Custom), Versus
- Multiplayer : Remote Play Together (Steam version)
- Platform : Windows 10, 11 (64-bit)
- Engine : Unity 2022.3.62f3
